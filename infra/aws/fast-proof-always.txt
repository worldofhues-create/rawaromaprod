# SHIP-RP: what infra/aws/ship.sh always runs, and what sends a change to the whole suite.
#
# Read by scripts/touched-tests.mjs. Two kinds of line, each with its reason after the #. A line with no
# reason is refused when the list is read, and a change that deletes a `test` file listed here is refused
# by ship.sh: this list is the floor under every fast deploy, so it shrinks only in a reviewed commit.
#
#   test <path>        runs on every ship, whatever changed
#   sensitive <glob>   a change under it runs the whole suite (`pnpm test`) before the deploy
#
# The rest of the rule (which tests a changed file selects) is in scripts/touched-tests.mjs and in
# infra/aws/DEPLOY_AWS.md section 7a.
